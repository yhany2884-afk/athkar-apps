# أذكار اليوم — النسخ الأصلية

مصحف حفص، أذكار، كتب الحديث والعقيدة، وقبلة دون إنترنت.

كل منصة بلغتها:

| المنصة | اللغة | المجلد | افتح بـ |
| --- | --- | --- | --- |
| أندرويد | Kotlin | `android/` | Android Studio |
| آيفون | Swift | `ios/Athkar/` | Xcode |
| ماك | Swift | `macos/AthkarMac/` | Xcode |
| ويندوز | C# | `windows/Athkar/` | Visual Studio أو `dotnet run` |

البيانات المشتركة في `data/` (مصحف كامل وكتب الحديث). لا تحتاج إنترنت بعد البناء.

## أندرويد

افتح مجلد `android` في Android Studio وابنِ APK.

## آيفون

افتح `ios/Athkar/Athkar.xcodeproj` في Xcode. يلزم حساب مطوّر للتثبيت على جهاز.

## ماك

افتح `macos/AthkarMac/AthkarMac.xcodeproj` في Xcode ثم Run.

## ويندوز

```
cd windows/Athkar
dotnet run
```
